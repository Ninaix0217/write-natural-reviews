# write-natural-reviews

创作自然、有具体体验和人物情绪的中文产品评价风格文本，或按原有事实润色真实反馈。

正式版本：**v1.0.0**。本版采用用户选定并恢复的版本，SKILL.md 与恢复后的工作基线一致。

## 写作逻辑

人群／场景 → 原有困扰 → 购买原因与产品身份 → 使用过程 → 体感与效果 → 对比和情绪 → 收尾。

经历链支撑内容，人物在意决定重心。允许在明确的虚构练习中补充符合产品、人物和生活逻辑的普通细节；真实反馈润色遵守已有事实与用户指定范围。

## 安装

下载 Release 中的 `write-natural-reviews-v1.0.0.zip`，解压后将 `write-natural-reviews` 文件夹放入本地 Codex 的 skills 目录（通常为 `~/.codex/skills/`）。

也可以将本仓库的 `SKILL.md` 保存为 `~/.codex/skills/write-natural-reviews/SKILL.md`。

## 使用示例

```text
使用 write-natural-reviews，按以下真实反馈写两条产品评价，每条约150—230字。
产品名称：……
真实体验素材：……
人物视角与本次要求：……
```

```text
使用 write-natural-reviews，做两条明确的虚构评价写作练习。
产品名称：……
假设体验素材：……
允许合理补写普通生活细节，突出人物最在意的事，避免两条重复。
```

## 版本与验证

本次正式发布固定已有版本，没有追加规则或修改文风。发布前核对工作基线、仓库内 SKILL.md 与安装包内 SKILL.md 的一致性，并验证 skill 的基本结构。

此前已用生长纹修复膏、半月板软膏进行独立工作区写作测试。已知仍需改善核心体验的分量与批量内容差异；正式发布不代表这些写作问题已全部解决。

虚构练习保持练习身份，不冒充真实买家评价。健康产品的名称不作为组织修复、治愈等功效的证据。
