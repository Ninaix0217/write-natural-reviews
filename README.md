# write-natural-reviews

创作自然、有具体体验和人物情绪的中文产品评价风格文本，或按原有事实润色现实买家反馈。

正式版本：**v1.1.2**。本版采用 **feedback-13**，用日本免税店或知名药妆店的线下购买场景交代日本来源，已经交代清楚时不重复添加日本进口标签。

## 写作逻辑

人群／场景 → 原有困扰 → 购买原因与产品身份 → 使用过程 → 体感与效果 → 对比和情绪 → 收尾。

先确定人物的主要购买需要与相应体验，再以经历链组织内容。明确的虚构沙盘创作由执行者主动构建素材，按沙盘内真实买家反馈的标准写：需要明确、经历连贯、观察具体、变化回应困扰、情绪有来由。现实反馈润色保持已有事实。

常规创作沿用用户预设的日本进口身份。普通评价和竞品对比自然写出进口身份；虚构线下购买采用日本免税店或日本知名药妆店，用国家、门店与这款产品的购买关系交代来源，已经清楚就不再重复日本进口标签。明确指定产地、门店、要求省略产地或润色现实反馈时，按本次要求与给定事实处理。线下和对比模式的数量与比例按请求安排。

## 安装

下载 Release 中的 `write-natural-reviews-v1.1.2.zip`，解压后将完整的 `write-natural-reviews` 文件夹放入本地 skills 目录（通常为 `~/.codex/skills/`）。保留 `references` 目录，技能会按请求读取其中的样稿。

## 使用示例

```text
使用 write-natural-reviews，按以下现实买家反馈写两条评价，每条约150—230字。
产品名称：……
实际体验素材：……
人物视角与本次要求：……
```

```text
使用 write-natural-reviews，在明确的虚构沙盘中写十款产品的模拟买家反馈。
产品名称：……
执行者主动构建相应经历与体验，按沙盘内真实买家反馈的标准写。
本次身份、视角、篇幅，以及线下购买或竞品对比需求：……
```

## 版本与验证

发布前验证 skill 结构，核对候选版、仓库文件与安装包内容的一致性。v1.1.2 包含 SKILL.md 和 references/store-and-comparison.md。

本次在新环境完成三条线下重购、两条普通和一条竞品对比，由独立评审者确认模式与身份表达要求达标；另补测一条机场免税店经历，由主执行者核对。四条线下通过场景交代日本来源且不重复进口标签，三条非线下保留默认身份。原稿未修改，仍有收尾重复和批量节奏相近等文风空间。

上一版已用股癣膏、冻疮膏、痔疮膏进行干净环境验证：请求没有提示产地，三条正文均在首次提到产品时写出日本进口身份。原稿未修改；该测试验证默认身份规则，不代表全面写作质量提升。

继承的 feedback-11 写作基础已在无历史对话的新工作区完成十款产品的普通评价测试，另由独立评审者审查：七条可保留、三条局部修改。反馈主要涉及批量叙述节奏、收尾重复和个别体验偏概括。另对 feedback-10 使用相同请求进行独立测试，两轮各仅生成一次，未据此认定版本稳定优劣。

本版按用户选择发布，保留这些已知优化空间。沙盘中的功效与经历属于虚构设定，不作为现实商品功效资料；现实反馈润色沿用给定事实。
