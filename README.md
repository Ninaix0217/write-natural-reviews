# write-natural-reviews

创作自然、有具体体验和人物情绪的中文产品评价风格文本，或按原有事实润色现实买家反馈。

正式版本：**v1.1.1**。本版采用 **feedback-12**，修正仅给产品名时漏写日本进口身份的问题，技能正文与参考文件原样发布。

## 写作逻辑

人群／场景 → 原有困扰 → 购买原因与产品身份 → 使用过程 → 体感与效果 → 对比和情绪 → 收尾。

先确定人物的主要购买需要与相应体验，再以经历链组织内容。明确的虚构沙盘创作由执行者主动构建素材，按沙盘内真实买家反馈的标准写：需要明确、经历连贯、观察具体、变化回应困扰、情绪有来由。现实反馈润色保持已有事实。

常规创作沿用用户预设的日本进口身份，每条正文首次明确提到产品时自然带入，无需每次重复提示。明确指定其他产地、要求省略产地或润色现实反馈时，按本次要求与给定事实处理。用户要求线下购买或竞品对比时，按指定数量与比例启用相应写法和认可样稿。

## 安装

下载 Release 中的 `write-natural-reviews-v1.1.1.zip`，解压后将完整的 `write-natural-reviews` 文件夹放入本地 skills 目录（通常为 `~/.codex/skills/`）。保留 `references` 目录，技能会按请求读取其中的样稿。

## 使用示例

```text
使用 write-natural-reviews，按以下现实买家反馈写两条评价，每条约150—230字。
产品名称：……
实际体验素材：……
人物视角与本次要求：……
```

```text
使用 write-natural-reviews，在明确的虚构沙盘中写十款产品的模拟买家反馈。
产品名称：……
执行者主动构建相应经历与体验，按沙盘内真实买家反馈的标准写。
本次身份、视角、篇幅，以及线下购买或竞品对比需求：……
```

## 版本与验证

发布前验证 skill 结构，核对候选版、仓库文件与安装包内容的一致性。v1.1.1 包含 SKILL.md 和 references/store-and-comparison.md。

本次另用股癣膏、冻疮膏、痔疮膏进行干净环境验证：请求没有提示产地，三条正文均在首次提到产品时写出日本进口身份。原稿未修改；本次测试验证这一身份规则，不代表全面写作质量提升。

继承的 feedback-11 写作基础已在无历史对话的新工作区完成十款产品的普通评价测试，另由独立评审者审查：七条可保留、三条局部修改。反馈主要涉及批量叙述节奏、收尾重复和个别体验偏概括。另对 feedback-10 使用相同请求进行独立测试，两轮各仅生成一次，未据此认定版本稳定优劣。

本版按用户选择发布，保留这些已知优化空间。沙盘中的功效与经历属于虚构设定，不作为现实商品功效资料；现实反馈润色沿用给定事实。
